# sing 0.6.0 — first public preview

sing is a native sing-box terminal client for subscriptions, proxy groups, routing and DNS. Everyday workflows have visible keyboard controls; the underlying native configuration stays available for advanced use.

## Highlights

- Five workspaces: Overview, Proxies, Routing, Network and Activity.
- Subscription preview/update and connection setup, one-transaction groups, and rule import with target binding.
- Supported QX/Clash list conversion performed locally; native JSON/Source/SRS resources preserve their native semantics.
- Independent DNS configuration, typed references, Review Changes and redacted Native Diff.
- API-confirmed live selection with separate remembered choices and Apply recovery.

## Install from source

This public preview is a **source release**, not a signed/notarized binary distribution. GitHub's source archives are available below; there is no bundled sing-box core, Homebrew formula or crates.io package.

```sh
git clone --branch v0.6.0 --depth 1 https://github.com/mmei0114/sing.git
cd sing
cargo build --release --locked
./sing --demo
```

Use Rust/Cargo (tested: 1.94.0) and a platform C linker. Exit the demo with `q`, run `./sing`, then install/select sing-box in **Settings → Core**. The built-in core installer verifies its pinned SHA-256.

## Verification and limits

Local verification: 122 ordinary tests and 9 explicit isolated/read-only tests passed on macOS arm64 with sing-box 1.14.0. [Public CI passed on macOS and Linux](https://github.com/mmei0114/sing/actions/runs/35065643935), covering formatting, ordinary tests, Clippy, release builds, version/preview execution and documentation links. This includes a fix to compile the macOS system-proxy backend only where supported, while retaining its portable transaction tests.

Real privileged System Proxy/TUN recovery, Linux/SSH networking and first-time user acceptance remain incomplete. Source-build CI is not proof of host-network safety or measured performance. TUN can interrupt SSH. See the [verification record](https://github.com/mmei0114/sing/blob/main/docs/acceptance-0.6.0.md).

## Existing users

Manager protocol is **9**. Close old interfaces and run `sing --shutdown` (or `./sing --shutdown`) only when you can interrupt the connection. Resolve any restoration failure before reopening. Back up private state before upgrading; never share it in an issue.
