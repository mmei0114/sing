# sing 正式客户端产品规格 v1

日期：2026-09-15；更新：2026-09-16。源码基线：0.5.1，公开版本：0.6.0；当前界面修订：0.6.1-dev（未发布）。M1/M2 代码流程与隔离验证已落地，M3 部分依赖及 M4 平台/用户验收仍未完成。逐项范围见 acceptance-0.6.0.md 与 progress.md，发布不等同完整目标验收。

本文取代 product-research-2026-09-15.md 的六页导航和独立原型建议，以及后续讨论中的三分区侧栏建议。旧研究仅作为素材，不作为实现指令。冲突时按用户最新明确指示 > 本规格 > 历史文档处理。

> **2026-09-17 导航修订：**用户最新指示将五个一级工作区收敛为 **Overview / Policies / Activity**。Policies 合并代理组、有序路由与来源；Activity 为 Connections / Apps / Logs，并允许从内核观测证据生成可编辑规则。Start / Mode / TUN 固定在底栏；低频配置由 Config 进入，并按 sing-box 原生顶层结构组织。下文“五工作区”描述保留为历史验收基线，但不再是当前实现指令。

## 1. 唯一实施目标

直接升级 sing 正式客户端：在保留现有 sing-box 原生配置语义、数据与运行能力的基础上，交付符合常见代理客户端习惯的英文 TUI。新手无需聊天指导或编写 JSON，即可导入节点订阅、选节点、建组、导入远程规则集并绑定目标、找到 DNS 设置；专家能够深入原生对象，查看引用、运行证据与配置变化。以下必需验收项全部通过，或用户明确批准范围调整后剩余必需项全部通过，才可判定目标完成；failed/not tested 不是通过。

范围：macOS 本机，以及 Linux 本机/SSH 的终端操作。SSH 内的程序控制的是远端主机，界面必须明示；不能误称接管了 SSH 发起端。直接在正式代码中分阶段实现，不开发另一套独立原型。不擅自启停用户正在运行的核心、切换主机代理或修改真实订阅。

## 2. 固定的信息架构

五个主工作区顺序固定：Overview / Proxies / Routing / Network / Activity。采用紧凑顶部导航，不使用常驻的三分区侧栏。Settings 为全局按钮，不占主工作区；低频高级能力不通过继续增加一级菜单解决。

| 工作区 | 子页面/区域 | 归属与默认行为 |
|---|---|---|
| Overview | 状态、常用组摘要、异常、初次引导 | 不再嵌套强制子页签；显示核心、接管、访问检查的独立状态；提供 Import Subscription、Change Proxy、连接控制的就近入口 |
| Proxies | Proxy Groups / Nodes / Subscriptions | 默认 Proxy Groups；订阅为节点来源，手动节点也可存在；Import Subscription 和 New Group 常驻可见 |
| Routing | Rules / Rule Sets | 默认有序 Rules；默认目标明确显示；Import Rule Set 和 Add Rule 常驻可见；Options 为页内高级操作，不省略原生 route 字段 |
| Network | Capture / Inbounds / DNS | Capture 管接管和权限；Inbounds 管具体入站；DNS 内含 Servers / Rules / Options，可用区段或局部页签，不要求层层菜单跳转 |
| Activity | Connections / Logs / Diagnostics | 默认 Connections；查询结果与错误不伪装为实时已验证状态 |
| 全局 Settings | Core / Interface / Client / Advanced Tools | 内核安装版本、英文界面偏好、客户端运行行为、维护与完整原生编辑；不重复列 DNS/节点/路由编辑页 |

导航不是数据包处理顺序，而是用户找功能的入口。Network 是产品工作区，不是新的 sing-box 配置对象。所有原生字段仍保留所属路径，产品视图不能改变其意义。

### 必须可见的熟悉入口

- Overview 与 Proxies：Import Subscription，打开同一流程；首次空状态以它为主操作。
- Proxies：Proxy Groups / Nodes / Subscriptions 三个标签直接可见；更新在 Subscriptions 内，支持 Update / Update All 并展示变化。
- 组详情：当前成员、候选成员、延迟、Test、Edit Members；选节点和编辑节点不是同一动作。
- Routing：Rules / Rule Sets；Import Rule Set 包含目标绑定；默认目标位于规则列表语境中。
- 底部全局控件：Start / Stop、Mode、Settings、Review、Help、Actions，旁显键位；Mode 打开 Rule / Global / Direct。Overview/Network 的相关快捷入口操纵同一状态，不复制另一套配置值。
- Overview 可直接进入 System Proxy / TUN / Proxy Ports 的接管选择；详细配置归 Network。TUN 不作为所有平台/SSH 的无条件默认。
- Network：DNS 标签直接可见；Activity：Connections 和 Logs 标签直接可见。
- 不用 Resources、Pipeline、Workspace 等自创分类替换用户熟悉的入口；tag/outbound/detour 在专家层仍能找到。

Subscriptions 暂定在 Proxies 内是本产品取舍，并非行业标准。若可用性验证证明不可发现，先改明显入口；需要提升为一级或改变结构时记录问题、给出方案并取得用户同意，不能自行来回调整。

## 3. 对象和数据的不可变约束

1. 同一份 native 文档为事实来源，表单局部修改；不得建立会覆盖原生文档的第二套简化配置生成器。
2. 每个对象只有一个权威编辑器，可通过多个摘要/选择器/深链接到达；不得复制 DNS、TUN 或组配置。
3. Proxy Groups 是原生 selector/urltest 等适用对象的友好视图。合法成员不限制为订阅节点 ID；支持合法出站/组引用并校验循环。Nodes 默认只展示代理节点，但提供 All Outbounds 高级视图覆盖 direct 等对象，不能将它们丢失或错误标为机场节点。
4. 显示名与稳定原生 tag 分离；修改显示名不改变引用。显式原生改名需检查并事务化更新所有可识别引用；无法保证时拒绝并指出原因，不冒充安全成功。
5. 节点订阅只更新其拥有的节点和来源元数据；保留用户组、DNS、路由。来源删除/改名导致引用冲突时显式审阅处理，不暗中删除依赖对象。节点订阅和完整配置导入严格区分。
6. Capture 为接管工作流和状态视图；TUN 本身是入站，Capture 引用/创建同一入站并跳到唯一编辑器，不产生独立副本。不以三选一快捷控件抹掉已有复杂入站组合；无法表示时显示 Custom 并允许保留。
7. Rule Sets 只有一份，Route 与 DNS 均可引用。列表显示使用者，删除前检查全部引用。DNS 选择器可选择/管理同一资源，不复制规则集。
8. Routing 保留原生顺序、逻辑条件、非终结处理动作和默认项。不能将所有规则缩成 domain → node。DNS 有独立的规则语义；默认解析器、bootstrap、拨号 detour 等分别展示职责和真实字段路径，跨视图修改仍是同一字段。
9. 无专用表单的原生字段/对象仍可访问并往返保留；现阶段没有完整表单不等于删除能力。版本/平台不支持时解释限制，不宣称覆盖未来所有 sing-box 功能。

## 4. 三条必须贯通的主流程

### F1：订阅到首次可用

Import Subscription → URL → 下载/识别/验证 → 预览节点与转换问题 → 保存 → 选择初始出口 → 选择接管方式 → Review & Start。

- 名称可自动建议；User-Agent 等按需展开；不得把私密 URL/节点凭据输出到日志、截图或 Git。
- 导入本身可单独完成，不强迫启动；已有配置不被入门向导重置。每个明确提交阶段可见，失败保留输入和已保存成果；取消未提交部分不留下半成品。
- 核心运行、系统接管、指定目标访问检测分别显示；SSH 明确控制哪台主机。失败有 Retry / Details / 返回编辑。

### F2：一次提交创建可用组

New Group → Name → Manual / Automatic → 搜索与多选成员 → 默认成员（适用于 Manual）→ Create Group。

- 成员选择属于同一编辑事务，不要求用户保存成员后再保存另一层；最终仅一次组提交。
- 合法组引用可选；搜索按名称/来源筛选；默认成员必须有效；空组/循环有定位错误。
- Automatic 展开测试地址/间隔/容差，准确映射内核类型。自动低延迟不代表吞吐、视频体验或解锁一定最好。仅筛选选中成员不冒充后续动态跟随订阅。
- 保存组进入草稿，显示 Review Changes。运行中切换组成员通过现有原生管理路径确认结果；失败不得留下成功高亮。

### F3：导入远程规则并完成分流

Import Rule Set → URL → 格式与转换预览 → Send Matching Traffic To → 位置预览 → Save → 全局 Review/Apply。

- 使用现有受支持的 QX/Clash 转换能力；明确不支持条目，不默默放宽、丢弃或假装等价转换。默认本机转换，不把订阅送给第三方服务。
- 原生 sing-box 规则集保留其原生类型与适用格式，不经过有损外部转换。
- 目标可直接选已有组/合法出口；可内联 New Group。内联新组、规则资源和路由引用作为一次保存事务；取消不留下新建孤立对象。
- 内联建组中的 Esc 只关闭该子表单并丢弃其未提交编辑（有编辑时确认），返回规则导入并保留之前输入；子表单的确认仅暂存到父事务。父流程退出会确认并丢弃整个未提交事务，只有最终 Save 才持久提交。
- 保留真实顺序，提示能够可靠检测的遮挡/无效位置；不能承诺完整静态推断所有复杂规则。
- DNS 默认不改变；若建议增加 DNS 规则，单独说明并获得确认。保存不是应用，反馈明确区分。

## 5. 统一交互与视觉

- 顶部固定主机/运行状态、模式与草稿标记，再放五工作区和子导航；中部工作内容；底部固定带键位的全局控制，上方一行上下文提示。接管证据集中在 Overview / Capture，避免顶部挤满等权文字。空通知不占行，错误仍保留。
- 页面布局：标题与可聚焦主操作 → 可见子导航/搜索 → 列表与详情。宽屏并排；80×24 采用列表进入详情、Esc 返回；详情保留滚动与焦点。
- Tab/Shift+Tab 只在内容与本页动作间切换；F6 直达底栏；1–5 直达工作区、方括号切子页，DNS 内容区左右切 Servers/Rules/Options。方向键选择、Space 勾选、Enter 执行明确动作、Esc 返回/取消。表单内仍按字段顺序 Tab；任何全局键不得截获输入，弹窗与筛选时底栏标明暂停。
- 切页记住每个 page/tab 的过滤与行选择，回到已删除行时夹到合法范围。引用跳转清理目标过滤，返回保留原上下文。视觉用克制的深色底、单一薄荷强调色、对齐与分隔线；选中导航、键盘焦点和实际运行选择不是同一种状态。
- 所有主要任务用可见控件完成，鼠标可选，键盘独立完成。Actions 搜索提供专家快速跳转和低频动作，不取代主要按钮，也不要求用户先背命令。
- 进入组详情与选中成员是不同焦点上下文；选节点不打开编辑器，测速不替手动组切换。
- 确认值、焦点、当前运行值、未应用草稿用不同文字/符号标记，不只依赖颜色。API 断开/未知/检查过期不展示成绿色已验证。
- 英文单语言，提示克制；无 Nerd Font 依赖；中文/Emoji 节点名正确计宽；长文本不遮挡按钮。测速刷新不抢焦点、不自动打乱正在操作的列表。
- 空状态有主动作；错误有重试/详情；字段错误定位；退出未保存表单时确认。秘密字段遮罩，截图/日志/导出默认脱敏。

## 6. 保存、运行与应用

- Save：持久保存配置草稿。Apply：校验并使草稿生效。Update Subscription：更新来源内容。三个动作明确区分。
- 运行时选择节点独立于结构草稿，使用现有原生控制路径；说明影响新连接还是现有连接，不保证所有连接立即迁移。运行值以 API 确认，不以点击推断。
- 手动组成功选择后记录“上次成功选择”，与原生默认成员字段分开；重启/Apply 后仅在同一组和成员仍合法、且没有明确修改该组默认成员时恢复。明确修改默认成员优先于旧选择，Review 提示选择变化。恢复失败必须展示失败/实际回读值，不展示缓存为 LIVE。Automatic 不锁定上次测速结果，仍由内核决定。外部原生缓存若已承担恢复，客户端不得与其竞争写入。
- 顶部模式控件保留熟悉名称；如改变模式需要重启，先说明并确认，未完成前显示 pending，不提前改写 LIVE。
- 模式沿用现有原生模式覆盖机制，不引入 Clash 转发层：Rule 使用保存的原生路由；Global/Direct 在运行配置中覆盖用户流量路由决策，保存的规则不删改，DNS/拨号依赖保留。Global 的目标与内网例外必须明确可见；切回 Rule 恢复原生规则。覆盖的具体处理动作和影响按现有实现审计并加入回归，不承诺复杂自定义配置无条件兼容；缺失目标/能力或无法安全构造覆盖时拒绝应用、保留当前运行，不能暗中简化配置。
- Review 默认给出可读对象/字段摘要（例如新增 YouTube → Media、DNS unchanged），可展开准确的原生 diff。显示接管、DNS、重启影响；全局 Direct 不得不加限定地承诺所有内部 DNS 请求也直连。
- 应用前检查配置、引用、版本与并发变化；失败保留可恢复草稿，反馈核心/网络恢复的实际结果。不得用“自动恢复成功”掩盖未验证恢复。
- 现有运行状态不因浏览/保存草稿而改变。开发测试用隔离目录、虚构凭据和回环端口，不动用户核心/系统代理。
